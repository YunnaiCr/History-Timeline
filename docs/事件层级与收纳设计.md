# 事件层级与跨年事件：设计答案

> 针对两个问题：
> 1. "缩放不只是画面缩放，还想让单个节点展开/收纳"——这算不算同一件事？
> 2. "甲午战争这种持续几年的事件里，还有具体到年月的子事件（黄海海战等），怎么穿插？"

## 一、先厘清三个容易混淆的概念

| 概念 | 触发方式 | 作用 | 实现 |
|---|---|---|---|
| **画面缩放** | 滚轮 / 快捷键 | 改 `pxPerDay`，时间轴变宽变窄 | ✅ 已做 |
| **收纳 / 展开** | 自动（阈值）+ 手动（点簇） | 挤在一起的节点收成 `N ↑` 徽标，点开散开 | ✅ M2 已做 |
| **事件折叠**（父子） | 点父事件上的 `▸N` | 父事件内部的具体事件展开/收起 | ✅ M2 已做 |

你说的"单个节点的缩放"，正确的名字是**收纳/展开**，它和画面缩放在物理上是**同一个变量的两种表达**：

```
pxPerDay  ↑  →  节点间距变大  →  超过阈值 →  自动散开
pxPerDay  ↓  →  节点间距变小  →  低于阈值 →  自动收成簇
```

所以不需要单独做"节点缩放"，只需要保证**阈值是像素单位**（`CLUSTER_PX = 30px`），而不是时间单位。这一点 M2 已经落实。

## 二、跨年事件（span）与子事件的穿插方案

这正是你担心的地方：甲午战争持续 1894–1895，而黄海海战是 1894-09-17 一天的事。**两者时间尺度差 2 个数量级**，强行放同一轨道必然出现"父事件卡片横跨全场，子事件缩成 1px"。

M2 采用的方案是**"轴线 + 上方子事件区 + 下方卡片区"三层布局**：

```
     ┌─ 子事件区（轴线上方）─────────────────────────────────
     │  ● 丰岛海战   ● 黄海海战   ● 威海卫之战   ●《马关条约》
     │  └────┬───────────┴──────────────┴────────────┘
══════╪══════╪══════════════════════════════════════════════  ← 主轴线
     │  [甲午战争 1894–1895]    [戊戌变法]     ...
     └─ 卡片区（轴线下方，按轨道排布）
```

规则：

| 情况 | 表现 |
|---|---|
| 父事件是**区间**（`endJdn` 存在） | 轴线上画一条彩色**区间带**，长度 = 持续时间 |
| 父事件**折叠** | 卡片标题右侧显示 `▸4`，告诉你"里面还有 4 个" |
| 父事件**展开** | 子事件在轴线上方按真实时间位置排列，用一条横线挂到父事件位置 |
| 子事件距离父事件太近（像素 < 6px） | 向右推 6px，避免叠成一点 |
| 放大超过 `1.2px/天` | 自动全部展开，不用手点 |

### 数据模型

```ts
Event {
  id
  startJdn, endJdn?          // endJdn 存在 = 区间事件
  parentId?: string          // 指向父事件，子事件不占轨道
  expandMode?: "span" | "point" | "collapsed"
  importance: 1 | 2 | 3      // 低缩放时的显示门槛
}
```

- `parentId` 是**单字段自关联**，不是嵌套树。数据库里就是一行一个事件，查询"甲午战争的所有子事件" = `WHERE parent_id = 'e5'`。
- 支持多层：孙事件用 `parentId` 指到父事件即可，渲染时递归展开。
- 示例数据已加：甲午战争（4 个子事件）、辛亥革命（2 个）、北伐（3 个）、抗日战争（4 个）。

## 三、为什么不用"嵌套时间轴"（子轴套在父区间里）

考虑过的方案，列出来备选：

| 方案 | 优点 | 缺点 |
|---|---|---|
| **A. 子事件挂上方（已采用）** | 时间位置真实、不重复画轴、放大自然衔接 | 子事件多时上方会挤，需按层叠 |
| B. 父事件展开成"迷你子轴" | 子事件尺度独立，可展示年/月 | 视觉复杂，缩放联动难做，代码量翻倍 |
| C. 子事件不入轴，放到侧栏列表 | 简单 | 失去"在时间轴上看到位置"的价值 |
| D. 子事件当成普通事件，只是用连线表示归属 | 实现最简单 | 无法表达"甲午战争整体"的持久性 |

**选 A**，因为它同时满足两件事：父事件的**持续性**（区间带）+ 子事件的**精确时间点**（上方刻度位置）。如果以后子事件多到上方放不下，再引入"垂直拖动的子事件走廊"。

## 四、还有一个你没问但马上会遇到的问题：祖孙三代

比如：

```
抗日战争（1937–1945）
└── 台儿庄战役（1938-03-16 ~ 04-07）
    └── 滕县保卫战（1938-03-15 ~ 03-18）
```

目前的 `parentId` 单字段足够表达，但渲染时需要**递归**：展开抗日战争 → 显示台儿庄；再点台儿庄 → 显示滕县。

M2 暂时只渲染一层（避免复杂度过高），递归留到 M3。数据结构已经支持，不用改表。
